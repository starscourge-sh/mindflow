# The Matrix is both its own page and a way to show Today

The Matrix (four boxes, urgent by date, important by flag) is useful for all open tasks when planning, and for only today's tasks when deciding what to do next. Rather than pick one, the Matrix page keeps every task, and Today gains a third view beside List and Page that shows only today's (and late) tasks in the same four boxes, with the same drag, order, menus and keys. "All tasks in Matrix" links one to the other. Commit b298985.
