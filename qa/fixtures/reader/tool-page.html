About cliamp

cliamp is a terminal music player that takes its look from the classic winamp skin, with a spectrum analyser, a playlist and an equaliser drawn entirely in text characters, so it runs happily over a remote shell or inside a tiling window manager without a single pixel of graphics.

It plays local files in the common formats, streams internet radio, and can read a folder as a playlist, remembering where you left off in each one. Every control has a key, and the keys can be changed in a small configuration file that lives beside your other dotfiles.

The player is written in Go and ships as one static binary for macOS, Linux and Windows, so installing it is a matter of a single command from the tabs above, and updating it is the same command again whenever a new release is announced.
